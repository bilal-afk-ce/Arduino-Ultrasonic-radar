# Arduino-Based Ultrasonic Radar System

## Overview

This project consists of an Arduino-based ultrasonic radar system designed to detect nearby obstacles and measure their distances at different angular positions.

An HC-SR04 ultrasonic sensor is mounted on an SG90 servo motor to perform angular scanning. The collected measurements are transmitted to a computer through serial communication and displayed on a radar-style graphical interface in real time.

## Project Objectives

- Detect nearby obstacles using ultrasonic waves.
- Measure object distances.
- Perform angular scanning using a servo motor.
- Transmit sensor data through serial communication.
- Visualize detected objects on a graphical radar interface.

## Hardware Components

| Component | Function |
|---|---|
| Arduino board | Main controller |
| HC-SR04 | Distance measurement |
| SG90 Servo | Angular scanning |
| Breadboard | Circuit prototyping |
| Jumper wires | Electrical connections |
| Computer | Data visualization |

## System Architecture

1. The servo motor positions the ultrasonic sensor.
2. The HC-SR04 measures the distance to nearby objects.
3. Arduino processes the measurements.
4. Data is transmitted to the computer through serial communication.
5. The graphical interface displays detected objects.
